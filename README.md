# P1 - Aplicativo Riocard

Projeto desenvolvido para a disciplina de Desenvolvimento de Aplicativos Híbridos.

O trabalho consiste na reprodução de algumas telas do aplicativo Riocard utilizando React Native com Expo.

## Telas desenvolvidas

- Tela inicial
- Meus cartões
- Tipo de recarga
- Serviços
- Seleção de cartões para recarga
- Perfil

## Tecnologias utilizadas

- React Native
- Expo
- TypeScript
- Expo Router

## Como acessar e executar o trabalho

Para acessar o projeto, faça o download pelo GitHub ou clone o repositório:

git clone https://github.com/Alex150773/p1-expo-riocard.git

Entre na pasta do projeto:

cd p1-expo-riocard

Instale as dependências:

npm install

Depois, execute:

npx expo start

Após iniciar, será exibido um QR Code no terminal.

Para visualizar no celular, instale o aplicativo Expo Go e escaneie o QR Code. O celular e o computador devem estar conectados à mesma rede.

Também é possível executar o projeto utilizando um emulador Android.
